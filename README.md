# Lead Prioritization

## Project Objective
The goal of this project is to predict whether a car purchase lead will result in a successful transaction between a buyer and a seller within **5 days** of the lead's creation. This is a binary classification problem focused on prioritizing high-potential leads.

## Repository Structure
The repository is organized as follows:
*   **`data/`**: Contains the datasets used for training and testing.
*   **`solution/`**: Includes the main solution code.
*   **`submissions/`**: Stores the final prediction files for submission.
*   **`requirements.txt`**: Lists all Python dependencies required to run the project.

## Getting Started
To get started with the project, follow these steps:

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/alexeyshumilov04/LEAD-PRIORITIZATION.git
    cd LEAD-PRIORITIZATION
    ```

2.  **Set up the environment**:
    It is recommended to use a virtual environment. Install the required packages:
    ```bash
    pip install -r requirements.txt
    ```

3.  **Run the solution**:
    Navigate to the `solution/` directory and execute the notebook to train the model and generate predictions.
